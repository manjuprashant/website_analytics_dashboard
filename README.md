# Website Analytics Dashboard

## 📊 Overview
This project provides an interactive dashboard to analyze website performance metrics such as traffic, user behavior, and conversions.

## 🔧 Features
- Traffic analysis (page views, sessions, sources)
- User engagement metrics (bounce rate, time on site)
- Conversion funnel visualization
- Top performing content insights
- Drill-through pages and interactive slicers
